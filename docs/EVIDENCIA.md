# Evidencia de entrega

Los resultados reales de tests y coverage se generan con un solo comando y quedan guardados en
[`docs/evidencia-salida.txt`](evidencia-salida.txt):

```bash
npm run evidencia
```

- **Tests:** debe terminar con `N passing` y `0 failing`.
- **Coverage:** debe superar 40 % en todas las métricas (la tabla está al final del archivo).
- **Slither:** ver [`SLITHER.md`](SLITHER.md).
- **Contratos y transacciones reales:** sección 9 del README (se completa con `node scripts/update-readme.js`).
- **Correcciones del docente:** [`CORRECCIONES.md`](CORRECCIONES.md).
- **Video:** link en la sección 8.4 del README.
